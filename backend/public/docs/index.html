Introduction

API REST de Sopi (réservation de services de proximité à Keur Massar). Préfixe /api/v1, JSON uniquement, erreurs en français : { "message": "...", "errors": { "champ": ["..."] } }.

Base URL: http://localhost:8000 
This documentation aims to provide all the information you need to work with our API.

<aside>As you scroll, you'll see code examples for working with the API in different programming languages in the dark area to the right (or as part of the content on mobile).
You can switch the language used with the tabs at the top right (or from the nav menu at the top left on mobile).</aside>

Authenticating requests

To authenticate requests, include an Authorization header with the value "Bearer {VOTRE_JETON}".

All authenticated endpoints are marked with a requires authentication badge in the documentation below.

Le jeton est renvoyé par POST /api/v1/auth/connexion ou /auth/inscription.

Prestataires

Inscription d'un prestataire

Envoi en multipart/form-data. Crée le compte (statut en_attente, il ne peut pas se connecter avant validation par un administrateur), le profil et les justificatifs. Le dossier doit contenir au moins une CNI et un diplôme ou une attestation (5 fichiers au maximum, PDF/JPG/PNG, 5 Mo chacun). Limité à 10 requêtes par heure et par adresse IP.

Le jeton_suivi n'est renvoyé qu'une seule fois : seul son hachage est conservé. Les chemins des fichiers ne sont jamais renvoyés.

Example request:
curl --request POST \
    "http://localhost:8000/api/v1/prestataires/inscription" \
    --header "Content-Type: multipart/form-data" \
    --header "Accept: application/json" \
    --form "nom=Diop"\
    --form "prenom=Moussa"\
    --form "telephone=77 123 45 67"\
    --form "email=moussa@example.com"\
    --form "mot_de_passe=mot-de-passe-exemple"\
    --form "nom_entreprise=Garage Moussa"\
    --form "metier=mecanique"\
    --form "quartier=Malika"\
    --form "adresse=Rue 10, près du marché"\
    --form "justificatifs[][type_document]=cni"\
    --form "justificatifs[][fichier]=@C:\Users\Moi\AppData\Local\Temp\phpDDBB.tmp" 
const url = new URL(
    "http://localhost:8000/api/v1/prestataires/inscription"
);

const headers = {
    "Content-Type": "multipart/form-data",
    "Accept": "application/json",
};

const body = new FormData();
body.append('nom', 'Diop');
body.append('prenom', 'Moussa');
body.append('telephone', '77 123 45 67');
body.append('email', 'moussa@example.com');
body.append('mot_de_passe', 'mot-de-passe-exemple');
body.append('nom_entreprise', 'Garage Moussa');
body.append('metier', 'mecanique');
body.append('quartier', 'Malika');
body.append('adresse', 'Rue 10, près du marché');
body.append('justificatifs[][type_document]', 'cni');
body.append('justificatifs[][fichier]', document.querySelector('input[name="justificatifs[][fichier]"]').files[0]);

fetch(url, {
    method: "POST",
    headers,
    body,
}).then(response => response.json());

Body Parameters

Nom. Le champ value ne doit pas dépasser 100 caractères. Example: Diop

Prénom. Le champ value ne doit pas dépasser 100 caractères. Example: Moussa

telephone   string     

Mobile sénégalais (avec ou sans +221), unique. Must match the regex /^+2217[05678]\d{7}$/. Example: 77 123 45 67

email   string     

Adresse e-mail, unique. Le champ value doit être une adresse e-mail valide. Le champ value ne doit pas dépasser 255 caractères. Example: moussa@example.com

mot_de_passe   string     

8 caractères minimum. Le champ value doit contenir au moins 8 caractères. Le champ value ne doit pas dépasser 255 caractères. Example: mot-de-passe-exemple

nom_entreprise   string     

Nom de l'entreprise ou de l'atelier. Le champ value ne doit pas dépasser 150 caractères. Example: Garage Moussa

metier   string     

mecanique, coiffure ou pressing. Example: mecanique

Must be one of:
  • mecanique
  • coiffure
  • pressing
quartier   string     

Quartier de Keur Massar. Le champ value ne doit pas dépasser 100 caractères. Example: Malika

adresse   string     

Adresse. Le champ value ne doit pas dépasser 255 caractères. Example: Rue 10, près du marché

justificatifs   object[]     

De 2 à 5 pièces : au moins une CNI et un diplôme ou une attestation. Le champ value doit contenir au moins 2 éléments. Le champ value ne doit pas contenir plus de 5 éléments.
type_document   string     

cni, diplome ou attestation. Example: cni

Must be one of:
  • cni
  • diplome
  • attestation
fichier   file     

PDF, JPG ou PNG, 5 Mo maximum. Must be a file. Le fichier ne doit pas dépasser 5120 Ko. Example: C:\Users\Moi\AppData\Local\Temp\phpDDBB.tmp

Changer mon mot de passe

requires authentication

Vérifie le mot de passe actuel, puis révoque tous les autres jetons de l'utilisateur. Le jeton courant reste valide.

Example request:
curl --request PUT \
    "http://localhost:8000/api/v1/me/mot-de-passe" \
    --header "Authorization: Bearer {VOTRE_JETON}" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --data "{
    \"mot_de_passe_actuel\": \"ancienmotdepasse\",
    \"nouveau_mot_de_passe\": \"nouveaumotdepasse\",
    \"confirmation\": \"nouveaumotdepasse\"
}"

const url = new URL(
    "http://localhost:8000/api/v1/me/mot-de-passe"
);

const headers = {
    "Authorization": "Bearer {VOTRE_JETON}",
    "Content-Type": "application/json",
    "Accept": "application/json",
};

    "mot_de_passe_actuel": "ancienmotdepasse",
    "nouveau_mot_de_passe": "nouveaumotdepasse",
    "confirmation": "nouveaumotdepasse"
