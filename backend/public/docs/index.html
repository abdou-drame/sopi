Introduction

API REST de Sopi (réservation de services de proximité à Keur Massar). Préfixe /api/v1, JSON uniquement, erreurs en français : { "message": "...", "errors": { "champ": ["..."] } }.

Base URL: http://localhost:8000 
This documentation aims to provide all the information you need to work with our API.

Authenticating requests

To authenticate requests, include an Authorization header with the value "Bearer {VOTRE_JETON}".

All authenticated endpoints are marked with a requires authentication badge in the documentation below.

Le jeton est renvoyé par POST /api/v1/auth/connexion ou /auth/inscription.

Administration — demandes d'inscription

Routes réservées aux administrateurs (jeton Sanctum + rôle administrateur).

Liste des demandes des prestataires

requires authentication

Paginée (20 par page). Par défaut les demandes en_attente, de la plus ancienne à la plus récente.

curl --request GET \
    --get "http://localhost:8000/api/v1/admin/prestataires/demandes?statut=en_attente&page=1" \
    --header "Authorization: Bearer {VOTRE_JETON}" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json"
const url = new URL(
    "http://localhost:8000/api/v1/admin/prestataires/demandes"
);

const params = {
    "statut": "en_attente",
    "page": "1",

Object.keys(params)

    --header "Content-Type: application/json" \
    --header "Accept: application/json" \

}"

requires authentication

Rechercher des prestataires

requires authentication

Paginée (20 par page). Ne renvoie que les prestataires dont le compte est actif et qui ont au moins une prestation active. Tous les filtres sont optionnels et combinables. Aucune donnée personnelle n'est renvoyée, et pas de note (les avis n'existent pas encore). La recherche ignore la casse mais pas les accents. prixMin et nombrePrestations portent sur toutes les prestations actives du prestataire.

Example request:
curl --request GET \
    --get "http://localhost:8000/api/v1/prestataires?metier=mecanique&quartier=Malika&q=vidange&prix_min=5000&prix_max=20000&tri=prix_asc&page=1" \
    --header "Authorization: Bearer {VOTRE_JETON}" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json"
const url = new URL(
    "http://localhost:8000/api/v1/prestataires"
);

const params = {
    "metier": "mecanique",
    "quartier": "Malika",
    "q": "vidange",
    "prix_min": "5000",
    "prix_max": "20000",
    "tri": "prix_asc",
    "page": "1",
