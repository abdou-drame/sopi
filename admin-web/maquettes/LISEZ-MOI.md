# Maquettes du back-office Sopi

Ces fichiers .dc.html sont des maquettes HTML : ouvre-les dans un navigateur ou lis leur code pour relever les tailles, couleurs et structures.
Chaque fichier = un écran. Main = Connexion (design actuel, NE PAS CHANGER). Guide = jetons et composants (boutons, badges, champs, alertes, confirmation).

Jetons principaux :
- Police Plus Jakarta Sans (400/500/600/700/800)
- Fond #eceef2, carte #fff rayon 32, surface douce #f3f4f7, texte #12172b, secondaire #6b7287, discret #8a90a2
- Accent #1d4ed8 (clair #e7edff), succès #16a36a, danger #e5484d, attention #fbbf24
- Boutons : hauteur 48, rayon 24, ombre bleue 0 8px 18px rgba(29,78,216,.30)
- Barre du haut : pilule blanche flottante ; rail gauche : 3 capsules d'icônes, sticky, centré verticalement, masqué < 900px
- Les textes et chiffres des maquettes sont des exemples : garder les vrais textes et les vraies données de l'application.
