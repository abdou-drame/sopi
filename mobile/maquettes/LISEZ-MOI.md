# Maquettes mobile Sopi — nouveau design (LA référence)

Ces 55 écrans 390×844 sont **le design de l'application mobile**. Chaque écran = `images/<Nom>.png` (rendu exact) + `html/<Nom>.html` (valeurs exactes : couleurs, rayons, marges, tailles de texte). `assets/` = logos Wave et Orange Money.

## Tokens (à reproduire dans le thème Flutter)

- Fond de tous les écrans : #f5f6fa uni (aucun dégradé, aucun halo)
- Cartes : blanc #ffffff, ombre 0 1px 3px rgba(18,23,43,.06), AUCUNE bordure
- Texte #12172b, secondaire #6b7287, icônes inactives #8a90a2
- Primaire #1d4ed8 ; boutons secondaires #e9ecf3 sans bordure ; champs #f1f3f8 sans bordure ; onglets segmentés fond #e9ecf3
- Boutons ronds du haut : 44×44, blancs, ombre 0 2px 8px rgba(18,23,43,.08), icône #12172b
- Barre du bas : pilule blanche flottante, ombre 0 8px 24px rgba(18,23,43,.12), onglet actif = pilule bleue
- AUCUN élément noir/marine (#0f1b3d interdit). Tailles et textes inchangés.
